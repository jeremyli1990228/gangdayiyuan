## 一、项目概述

### 1.1 对接目标

通过微信公众号接入患者投诉反馈渠道，实现患者通过微信提交投诉建议，后台系统自动接收并处理。

### 1.2 对接范围

| 模块   | 功能描述                |
| ---- | ------------------- |
| 用户授权 | 患者通过微信授权登录，获取微信用户身份 |
| 投诉提交 | 患者通过微信网页提交投诉建议表单    |
| 数据接收 | 后台系统接收并存储投诉数据       |
| 进度通知 | 向患者推送投诉处理进度通知（可选）   |

### 1.3 对接模式

采用 **微信公众号网页授权 + H5表单页面** 的方式，患者点击公众号菜单或分享链接，进入投诉提交页面。

## 十、风险与注意事项

### 10.1 常见风险

| 风险项       | 风险描述            | 应对措施      |
| --------- | --------------- | --------- |
| 公众号未认证    | 接口权限受限，无法使用模板消息 | 提前确认认证状态  |
| 域名ICP备案   | 国内服务器需完成ICP备案   | 提前准备备案材料  |
| Token验证失败 | 配置不正确导致验证失败     | 仔细核对配置信息  |
| IP白名单     | 测试环境IP变更需重新配置   | 固定IP或动态更新 |

### 10.2 安全注意事项

- AppSecret 请通过加密渠道传递，勿通过明文邮件
- 生产环境配置需单独管理，定期更换Token
- 用户隐私数据需加密存储
